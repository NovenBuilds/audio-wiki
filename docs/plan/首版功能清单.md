# 有声 Wiki 首版功能清单

日期：2026-11-05。
文档状态：用户已确认的首版功能规划，所有功能均待实现与验收。
依据：[网页程序实施计划](./网页程序的具体实施计划.md)、[网页首版管线设计](./2026-11-05-Web首版管线设计.md)及本轮用户确认。
当前执行状态见[项目上下文](../../CONTEXT.md)。

## 一、目标与交付边界

首版交付单用户、自托管的网页程序，先验收桌面浏览器。使用者自备人格技能、书籍知识及真人参考声音，完成：

**准备资料 → 组合课程 → 审阅首节 → 克隆音色讲授 → 文字提问 → 同音色回答 → 原位置续播。**

功能按三个批次管理：

- **闭环必需**：首个可使用版本必须具备。
- **首版补齐**：闭环完成后补齐，正式首版交付前必须具备。
- **后续增强**：不作为首版交付条件。

本次已确认：

- **首节确认后，后续自动生成**：先审阅首节讲稿并确认声音体验，再按有限预取继续；后续讲稿仍可暂停审阅和修改。
- **人声处理支持导入外部处理版**：保留原版、处理版及来源，内置人声分离服务延后。
- 首版先导入现成人格、书籍知识技能，完整自动提炼流程延后。
- 所有条目均为待实现功能，不能据此标记开发或验收完成。

## 二、五类页面功能

### 1．资料库

| 编号／批次 | 功能 | 操作、输入与输出 | 异常处理及完成标准 |
|---|---|---|---|
| 资料01／闭环必需 | 导入章节原文 | 导入一个章节，填写书名及章节信息，形成可阅读的原文记录 | 导入失败说明原因；成功后正文完整、来源可查 |
| 资料02／闭环必需 | 导入书籍知识技能 | 导入已提炼的框架、原则、方法、适用条件和反模式，关联书籍及章节 | 不将技能降格为普通摘要；缺少原书时明确标示依据范围 |
| 资料03／闭环必需 | 审阅与修订资料 | 查看、修改知识技能和章节关联，保存新版本 | 原版本仍可追溯；修订不悄悄改变已绑定的课程 |
| 资料04／闭环必需 | 查看原文依据 | 从讲稿或回答进入对应章节、段落，查看原文 | 定位失败明确提示；没有可靠页码时不生成虚假页码 |
| 资料05／首版补齐 | 导入整本书及校阅章节 | 保存原文件，解析目录与章节，允许修订章节名称、顺序及正文归属 | 解析不完整时列出问题，修订后再用于课程生成 |
| 资料06／首版补齐 | 资料复用与管理 | 查看资料版本、处理状态和关联课程，将同一知识技能用于不同课程 | 替换资料前显示影响范围，保留既有课程所绑定的版本 |

### 2．人格与声音

| 编号／批次 | 功能 | 操作、输入与输出 | 异常处理及完成标准 |
|---|---|---|---|
| 人声01／闭环必需 | 导入人格技能 | 导入思维框架、判断原则、表达特点、反模式及适用边界 | 显示内容与来源供审阅；导入资料不执行其中的脚本或工具指令 |
| 人声02／闭环必需 | 修订与版本化人格 | 编辑人格技能，保存独立版本，供课程选择 | 修改产生新版本；原课程继续使用已绑定版本 |
| 人声03／闭环必需 | 登记已有克隆音色 | 选择服务、型号及后端账号配置，登记已有音色并验证可用性 | 不兼容或不可用时说明原因，不自动替换成系统声音 |
| 人声04／闭环必需 | 短稿试听与预设保存 | 使用固定短稿试听，调整模型支持的朗读设置，保存声音版本与预设 | 分别确认音色、节奏、背景和朗读完整性；不能只凭文件可播放认定通过 |
| 人声05／首版补齐 | 音频与视频素材入口 | 上传音频；或上传视频、选择音轨并提取参考音频 | 无音轨、损坏、不支持的格式明确报错；原文件不覆盖 |
| 人声06／首版补齐 | 选择参考片段及处理版本 | 试听素材、选择时间范围，导入外部处理版并与原版对照 | 保留原件、来源及时间范围；不能将提取音轨标记为已经去除背景音乐 |
| 人声07／首版补齐 | 从参考音频创建音色 | 按所选模型要求准备参考音频并创建真人克隆音色 | 保存服务、型号及参考版本；创建结果不明时停止重试，进入待核对状态 |
| 人声08／首版补齐 | 声音版本管理 | 修改参考片段、处理版本或克隆设置，形成新的声音版本 | 不覆盖旧音色记录，不跨型号或账号配置误用音色 |

### 3．课程工作台

| 编号／批次 | 功能 | 操作、输入与输出 | 异常处理及完成标准 |
|---|---|---|---|
| 课程01／闭环必需 | 创建课程 | 选择书籍与知识技能版本、人格版本、声音版本、讲解深度及章节范围 | 缺少必要输入时指出具体缺项；创建后能查看完整组合 |
| 课程02／闭环必需 | 生成课程目录 | 根据选定内容形成课节安排，展示每节目标与原文关联 | 不编造未提供的章节；生成失败保留配置并允许重新发起 |
| 课程03／闭环必需 | 生成有依据的讲稿 | 生成学习目标、概念、解释、例子及章节依据 | 区分作者观点、讲解者解释和新增例子；依据不足时明确说明 |
| 课程04／闭环必需 | 首节审阅与确认 | 查看、修改首节讲稿，确认后合成并试听；内容与声音确认后开启后续自动生成 | 首节未确认不自动扩展生成；试听不满意时可以返回修改 |
| 课程05／闭环必需 | 独立朗读计划 | 根据讲稿形成语义分段、读音处理及模型支持的节奏设置 | 原讲稿与朗读变换分别保留；不支持的控制明确显示 |
| 课程06／闭环必需 | 分段合成与有限预取 | 首节优先，按顺序合成可播放片段，提前准备有限的后续内容 | 不默认整本合成；达到生成范围或用量上限后停止提交新任务 |
| 课程07／首版补齐 | 后续讲稿审阅及局部重做 | 暂停后续生成，修改指定讲稿或朗读设置，只重做受影响内容 | 未修改的产物继续复用；正在听的旧版本不与新音频混播 |
| 课程08／首版补齐 | 更换人格或声音 | 显示变更影响，由使用者明确应用到课程新版本 | 换声音复用书籍解析和知识技能；不静默改变现有课程进度 |

### 4．播放与提问

| 编号／批次 | 功能 | 操作、输入与输出 | 异常处理及完成标准 |
|---|---|---|---|
| 播放01／闭环必需 | 连续播放 | 播放、暂停、定位及切换课节，按顺序播放已就绪片段 | 无丢段、重复或乱序；下一段未就绪时显示等待或失败状态 |
| 播放02／闭环必需 | 保存真实播放位置 | 保存课程及讲稿版本、当前片段和段内位置 | 使用播放器实际位置，不能用后台生成进度替代 |
| 播放03／闭环必需 | 暂停并文字提问 | 点击提问立即暂停，保存课程位置，再提交问题 | 取消提问可返回原位置；提交失败保留问题文本 |
| 播放04／闭环必需 | 有依据的同音色回答 | 结合已听内容、人格技能、书籍知识及必要原文生成回答并朗读 | 不把尚未播放的内容当作已经听过；依据不足时说明，声音失败不自动换音色 |
| 播放05／闭环必需 | 回答后续播 | 回答结束后恢复原课程位置，提供“从当前句重听” | 用户主动暂停或中断后不擅自续播；浏览器阻止自动播放时提供继续按钮 |
| 播放06／闭环必需 | 刷新及重启后恢复 | 重新打开课程，恢复已保存位置和已生成产物 | 不重复创建已完成任务；恢复后由使用者点击继续播放 |
| 播放07／首版补齐 | 连续追问与中断回答 | 围绕当前问题追问，或停止回答并返回课程 | 追问不覆盖课程位置；旧回答迟到后不得突然进入播放 |

### 5．服务设置

| 编号／批次 | 功能 | 操作、输入与输出 | 异常处理及完成标准 |
|---|---|---|---|
| 设置01／闭环必需 | 查看服务配置状态 | 查看后端已配置的语言模型、声音服务、型号及连接状态 | 缺少配置时指出缺项；浏览器不接收或保存原始服务密钥 |
| 设置02／闭环必需 | 查看模型能力 | 展示当前模型支持的音色准备、语速、停顿、表达及取消能力 | 不支持的选项不可伪装可用；后处理与模型原生控制明确区分 |
| 设置03／首版补齐 | 生成范围与用量限制 | 设置预生成范围及用量上限，查看当前使用情况 | 达到上限后停止新增调用；估算与实际账单分开，不承诺精确费用封顶 |
| 设置04／首版补齐 | 运行状态与诊断 | 查看任务失败原因、耗时、可取得的实际用量和恢复入口 | 无用量数据时显示未知；日志和页面不暴露凭据或私有下载信息 |

## 三、跨页面的必需行为

这些能力复用到上述页面，不另增第六类页面。

| 编号／批次 | 行为 | 完成标准 |
|---|---|---|
| 通用01／闭环必需 | 后台任务持久保存 | 页面关闭后任务可继续；后端重启后已完成产物保留，未完成任务显示可解释的恢复状态 |
| 通用02／闭环必需 | 失败恢复与计费请求保护 | 区分生成失败、接收失败和结果不明；接收失败优先恢复已有结果，结果不明不能自动重新创建或合成 |
| 通用03／闭环必需 | 版本和音频复用 | 使用相同有效输入时复用已有产物；输入变化后不误播旧结果，重试不重做已完成部分 |
| 通用04／首版补齐 | 回答优先及停止后续生成 | 提问回答优先于尚未开始的课程预生成；停止生成不删除已就绪音频，不将“停止等待”当作计费请求已撤回 |
| 通用05／闭环必需 | 私有资料与凭据隔离 | 素材及产物通过授权入口访问；密钥不进入浏览器、仓库和日志；向云端提交资料时能知道使用了哪个服务 |
| 通用06／首版补齐 | 部署与恢复说明 | 提供首次配置、启动、资料存放及重启恢复说明，并在全新环境核验 |

首版的原文取用以章节和段落为基础，不要求引入向量数据库。文件格式白名单、具体框架、首个模型、接口字段及存储方案，按前置计划在架构阶段确定；不能在功能清单中宣称支持所有格式或所有模型。

## 四、后续增强

以下能力保留方向，不阻塞首版：

- 内置类女娲人格提炼、书籍转技能的完整生成与校阅流程。
- 内置人声分离及其他参考音频增强服务。
- 语音提问、持续监听、回声处理。
- 流式首播及更低等待时间的播放优化。
- 更多声音模型、本地推理服务及更复杂的跨章检索。
- 移动端后台播放、原生客户端、多用户及跨设备同步。
- 课程音频导出、公开分享、插件市场等未纳入前置首版范围的功能。

## 五、验收与文档交付

### 首个闭环验收

使用一份已审阅人格技能、一个章节及知识技能、一个真实克隆音色，完成首节确认、分段播放、段中提问、同音色回答和原位置续播；刷新及后端重启后可以恢复。

### 首版补齐验收

- 音频、单音轨及多音轨视频正确接入；损坏、无音轨及不支持格式给出明确反馈。
- 原件、处理版、参考片段和声音版本可追溯。
- 完整章节连续播放无丢段或重复；追问、中断和旧回答迟到不破坏课程位置。
- 超时、接收失败和重启不造成隐性重复合成；修改讲稿或声音只重做必要产物。
- 用户分别接受内容依据、人格表达、音色、节奏、背景及朗读完整性。
- 离线检查、真实服务验证、用户试听和完整交互验收分别记录，不互相替代。
