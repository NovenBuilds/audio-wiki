## 最新实验状态

以下是前置文档中的历史实测与用户反馈，不是本次新增验证，也不是六款模型的统一性能排名。

| 路线或样本 | 已记录结果 | 尚未证明的部分 |
|---|---|---|
| 本地 CosyVoice | 用户反馈最像、自然，但有背景音乐残留 | 音乐清理、长章节及应用完整流程 |
| 云端 MiniMax 初轮 | 用户认可音色相似及无漏读，反馈快、停顿少、有音乐残留 | 可接受的节奏、背景与自然度 |
| 百炼 Qwen、CosyVoice 初轮 | 用户认可音色相似、无漏读和背景干净，反馈快、少停顿 | 长时听感与应用交互 |
| 百炼显式停顿版本 | 七份调速／降噪对照中全部完整解码；Qwen 三档随后被否定停顿和起音噪声 | 其他样本未获明确确认的听感仍待试听 |
| Qwen 1.3／1.4／1.5、MiniMax 1.2／1.4 | 五份完整解码；用户明确反馈语速偏快 | 未确认其他听感通过 |
| MiniMax 0.9／0.8 | 两份变慢，但仍不自然、缺合理停顿；0.8 背景残留更明显 | 不能由同一音色的两份单样本推断语速导致降噪差异 |
| 标点分段／少量停顿候选稿（准备阶段历史） | 当时只准备文本并核对字词，用户随后截短并修改 | 此行不是后续实际提交版本的描述；后续结果见下行及补记 |
| MiniMax 用户修改短稿 A／B | 两次合成完成，用户主观接受两版，并能感受到换行、定时停顿和换气 | 仅为短稿接受；字幕定位、长章节、人格与书籍链路及提问续播未验收 |

本轮架构已确定先接入 MiniMax，默认 B 类定时停顿预设、A 类换气预设可选，最终模型效果排名未确定。文件完整解码与服务完成不等于没有漏读、声音自然或用户验收通过；短稿接受不外推为完整章节通过。

### 用户修改短稿 A／B 接受补记

- 来源：[实验说明中的实际合成与接受记录](/Users/ssr/project/evolution_lab/audio-wiki-cloud-comparison/README.md)、[自然度记录中的用户主观接受](/Users/ssr/project/project-nursery/voice-assistant/audio-wiki/research/2026-11-05-无显式停顿语速对照与起音检查.md)。
- 固定条件：MiniMax `speech-2.8-hd`、既有降噪开启音色、语速 0.9、音量 1、音调 0；没有新克隆、参考上传或后期修音。
- 实际 A 为用户截短稿，含 3 处换气标签，时长 35.724 秒；B 为用户截短稿，含 4 处 0.35 秒停顿，时长 32.851 秒。正文、段落及标签不同，不再套用准备阶段“仅改标点／两处停顿”的描述，也不作为严格单变量对照。
- 用户已明确主观接受两份短稿。该反馈用于首个工程接入与试听预设选择，不能作为客观自然度评分或完整应用验收结论。
- 本次只更新摘要，原输入、提交快照、音频、资产编号和实验程序继续留在来源目录。更新来源的本轮校验值见[架构设计的来源记录](./plan/架构设计.md#来源与证据记录)。

## 实验逻辑复用线索

- `run_compare.py`：参考音频检查、按服务和型号隔离音色、创建状态不明时停止、结果接收及音频检查。
- `run_cosyvoice_websocket.py`：CosyVoice 完整事件流接收；历史一次性请求曾产生异常短音频，不能直接沿用作完整结果。
- `run_controls.py`：语速、显式停顿与克隆阶段降噪对照；克隆与合成设置应分别记录。
- `run_speed_followup.py`、`run_minimax_slower.py`：复用既有音色的语速对照与结果复用。
- `run_user_prosody.py`：按用户实际修改的 A、B 短稿和已接受条件生成、保存提交快照并复用完整结果；其中固定的实验校验值不能直接作为产品通用规则。
- `test_compare.py`、`test_controls.py`、`test_speed_followup.py`：离线异常和参数检查参考；本次没有执行，不把旧测试数写作本仓库成绩。

这些文件位于前置实验目录，尚未迁入产品。后续复用前要检查接口现状、任务持久化、配置注入、错误信息、取消行为和测试边界，不能复制真实配置、音色缓存或私有下载记录。
